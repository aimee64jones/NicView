# Contributing to NicView

## Contribution Guidelines
We welcome contributions! To contribute:
- Fork the repository.
- Create a new branch for your changes.
- Follow the project's coding standards.
- Commit your changes and push to your fork.
- Open a pull request to the main branch.

## How to Contribute
1. Review open issues and discussions.
2. Work on bug fixes, new features, or documentation improvements.
3. Ensure your code passes tests and linting.
4. Submit a pull request with a clear description.

## Reporting Issues
- Use the GitHub Issues tab.
- Provide steps to reproduce, expected behavior, and screenshots if applicable.

## Suggesting Features
- Open a feature request issue.
- Clearly describe the feature, its purpose, and potential benefits.

## Code of Conduct
- Be respectful and inclusive.
- Avoid offensive language.
- Collaborate constructively.

## Review Process
- Maintainers will review pull requests.
- Feedback may be requested before merging.
- Approved contributions will be merged into the main branch.
